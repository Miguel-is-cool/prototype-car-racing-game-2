Prototype of a two-player car racing game, with the objective of crossing the red line (finish line) to win the game, without colliding with obstacles.

---
## 📚 Lessons learned
- HTML Fundamentals
- Page Creation and Hosting
- JavaScript Fundamentals
- Prototyping

## ⚙️ Features
- Move using the right, up, and down arrow keys for the blue car
- Move using the W, S, and D keys for the green car
- Avoid colliding with obstacles
- Win if you reach the finish line

## 🛠️ Stack
- JavaScript
- HTML5
- CSS3
